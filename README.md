# TextToMove
Type your chess moves instead of playing them yourself


## How does this work

TextToMove creates a small input box on the chess.com site you can then enter your moves in there the extensions shows you legal moves once a move is entered you can submit it and it will be played

- game starts
- code grabs the current board FEN code
- using the chess.js module it determineas legal and illegal moves
